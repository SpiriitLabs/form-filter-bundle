# Installation

The bundle can be installed using Composer or the [Symfony binary](https://symfony.com/download):

```
composer require spiriitlabs/form-filter-bundle
```

## Requirements

| Requirement | Version |
|-------------|---------|
| PHP | 8.1+ |
| Symfony | 6.4, 7.4, 8.0, 8.1, 8.2 |
| Doctrine ORM | 3.0+ |
